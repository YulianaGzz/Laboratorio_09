# Laboratorio 09 — Entrada Salida (IO) en Java

## Objetivo
Implementar un sistema de personajes RPG que pueda **guardar y recuperar información** del roster, inventario y bitácora de batallas utilizando archivos de texto. El propósito es aplicar conceptos de entrada/salida en Java y reforzar la programación orientada a objetos con manejo de excepciones personalizadas.

## Conceptos principales
- Persistencia de datos con `BufferedWriter` y `BufferedReader`.
- Organización de información en formato CSV sencillo.
- Reconstrucción de estructuras (`ArrayList`, `HashMap`) a partir de archivos.
- Manejo de excepciones personalizadas para controlar errores propios del juego.
- Modularidad del código separando lógica de personajes, persistencia y reglas.
